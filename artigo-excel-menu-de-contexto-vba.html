Aprovar com o botão direito: um menu de contexto sob medida no Excel

Como acrescentar itens próprios ao menu da célula com VBA e ligar cada clique a totais que se atualizam sozinhos.

Gilberto GomesExcel Essencial · 26 de novembro de 20269 min de leitura

Planilha de aprovação costuma ter o mesmo ritual: o gestor seleciona a linha, vai até a coluna de status e digita Aprovada, Reprovada ou Pendente, com a chance de errar a grafia a cada vez. Dá para trocar tudo isso por um clique com o botão direito, com os três comandos aparecendo no menu da própria célula. É um recurso de VBA curto, e o resultado se parece com um pequeno sistema.

Baixe a planilha do exercício: modelo-excel-menu-de-contexto.xlsm e modelo-excel-controle-de-adiantamentos.xlsx. O arquivo .xlsm traz a macro pronta. O .xlsx traz a mesma planilha sem macro, só com os totais por SOMASE, para quem prefere estudar as fórmulas antes.

O cenário: solicitações de adiantamento

A planilha do exercício controla solicitações de adiantamento de viagem: data, funcionário, descrição, valor e status. Embaixo, os totais: aprovado, reprovado, pendente, pendente e prioritário, atrasado e geral. O desafio é fazer o status mudar sem digitação e os totais responderem na hora.

O que aparece na imagem é a ideia central: o menu que se abre com o botão direito ganha três itens. Quem seleciona uma ou várias linhas e escolhe um deles grava o status em todas de uma vez.

O ciclo de vida do menu

O ponto de atenção é que o menu de contexto pertence ao aplicativo Excel e não à pasta de trabalho. Se a macro apenas adicionar os itens, eles continuam aparecendo em qualquer outro arquivo aberto depois. Por isso o desenho correto tem duas pontas: acrescentar o menu quando a pasta é ativada e removê-lo quando ela é desativada.

O código, em duas partes

A primeira parte vive no módulo da pasta de trabalho (EstaPasta) e liga os dois eventos:

Private Sub Workbook_Activate()
    AddToCellMenu
End Sub

Private Sub Workbook_Deactivate()
    DeleteFromCellMenu
End Sub

A segunda fica num módulo comum. Ela pega o menu da célula, acrescenta três botões antes dos itens existentes e marca cada um com uma etiqueta (Tag), que é o que permite achá-los e removê-los depois:

Sub AddToCellMenu()
    Dim ContextMenu As CommandBar
    Dim ctl As CommandBarControl
    Set ContextMenu = Application.CommandBars("Cell")

    Set ctl = ContextMenu.Controls.Add(Type:=msoControlButton, before:=1)
    With ctl
        .Caption = "Aprovar solicitação"
        .OnAction = "Aprovar"
        .FaceId = 1087
        .Tag = "Menu_celula_Excelline"
    End With
    ' idem para "Reprovar solicitação" (before:=2, FaceId 1088)
    ' e "Marcar como Pendência" (before:=3, FaceId 1089)
End Sub

Sub DeleteFromCellMenu()
    Dim ctl As CommandBarControl
    For Each ctl In Application.CommandBars("Cell").Controls
        If ctl.Tag = "Menu_celula_Excelline" Then ctl.Delete
    Next ctl
End Sub

Repare nos três detalhes: OnAction aponta para o nome da macro que será executada, FaceId escolhe o ícone entre os que o Excel já traz e Tag identifica os itens do projeto sem tocar nos originais.

A macro que grava o status

Cada item chama uma macro curta. Ela percorre as células selecionadas e, para as que estiverem na área da tabela (linhas 8 a 17, colunas B a F), escreve o status na coluna F:

Sub Aprovar()
    Dim c As Range
    For Each c In Selection
        If c.Row >= 8 And c.Row <= 17 And c.Column >= 2 And c.Column <= 6 Then
            Cells(c.Row, 6).Value = "Aprovada"
        End If
    Next c
End Sub

Reprovar e Pendência são idênticas, trocando só o texto. O teste de linha e coluna é a rede de segurança: se o usuário clicar com o botão direito fora da tabela, nada é gravado. E como o status é gravado pela macro e não digitado, deixa de existir a variação de escrita que quebra totais.

Os totais que respondem na hora

Com o status padronizado, a soma por situação fica simples. A SOMASE soma os valores de uma coluna quando outra coluna atende a um critério, e a SOMASES aceita vários critérios ao mesmo tempo, como pendente e acima do limite de prioridade. Já a de atrasados compara a data de cada solicitação com a função HOJE.

O limite de prioridade está numa célula nomeada. Em vez de fixar 250 dentro da fórmula, a SOMASES lê PRIORIDADE, e quem administra a planilha muda o critério sem abrir fórmula nenhuma.

Cuidados antes de distribuir

  • Formato do arquivo: macros só ficam guardadas em .xlsm. O usuário precisa habilitar o conteúdo ao abrir, e vale distribuir somente a partir de fonte confiável.
  • Onde roda: VBA funciona no Excel para computador. As versões na web não executam macros.
  • Ranges conferidos: o modelo original tinha uma das fórmulas somando E8:E11 contra critérios em F8:F17, e por isso ignorava as linhas de baixo. Os dois arquivos para download já estão corrigidos. Intervalos de tamanhos diferentes não dão erro, apenas número errado.
  • Auditoria: a macro sobrescreve o status sem registrar quem mudou. Se a decisão tem valor de controle, acrescente data, usuário e histórico antes de usar na prática.

O padrão vale muito além de aprovações: classificar alertas de fraude como procedente ou improcedente, marcar conciliações como conferidas, tratar filas de exceção. É um jeito de transformar a planilha em ferramenta de trabalho com poucas linhas de código.
